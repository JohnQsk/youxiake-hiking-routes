# 徙野 / Youxiake Hiking Routes

一个前期公开实验：把上海出发的一日徒步路线整理成可溯源的数据，并按**参考车程、徒步距离、累计爬升**比较。

- 静态网站：无需框架、无需后端、无需外部前端资源
- 种子数据：21 条路线，来自一张游侠客 App 候选截图
- 官方核对：2026-11-05
- 数据来源：游侠客公开活动详情页；每条记录保留链接、核对日期和短摘录
- 非游侠客官方项目，不提供报名服务

## 网站

GitHub Pages：`https://johnqsk.github.io/youxiake-hiking-routes/`

本地运行：

```bash
python -m http.server 8000
```

打开 `http://127.0.0.1:8000`。请通过 HTTP 访问，不要直接双击 `index.html`，因为浏览器通常不允许 `file://` 页面读取 JSON。

## 已支持

- 按官方参考车程、徒步距离、累计爬升升降序排列
- 按路线名称或活动 ID 搜索
- 按车程上限、累计爬升上限筛选
- 多方案路线逐行切换，排序随当前方案更新
- 缺失值显示“未公开”，排序置底，不作为 0
- JSON 主数据及每方案一行的 CSV 导出

## 数据边界

这批数据是 2026-11-05 的公开详情快照，不是游侠客全量路线库。

- **车程**是官方写明的单程或分段参考时间，不是实时导航时间。
- **距离和爬升**不等于完整难度；天气、路况和个人体能仍需另行判断。
- 多方案、多季节和接驳条件使用 `hiking_options` 表达，不强行合并成唯一数值。
- 未知字段为 `null`，不会用最高海拔、下降或某段接驳距离冒充总量。
- 班期、暂满、价格、天气属于动态信息，不在本静态数据集中维护。
- 实际路线和安排以官方最新页面及出团通知为准。

## 数据结构

`data/routes.json` 顶层包含 `schema_version`、`checked_at`、`scope` 和 `routes`。

每条路线主要字段：

| 字段 | 含义 |
|---|---|
| `id` / `source_url` | 官方活动 ID 与可回跳来源 |
| `name` / `short_name` | 官方完整标题与表格短名称 |
| `departure_city` / `days` | 出发城市与活动天数 |
| `drive_time` | 排序用分钟数、区间及官方文字 |
| `hiking_options` | 路线方案、距离、累计爬升及备注 |
| `source_excerpt` | 支持数据理解的必要短摘录 |
| `checked_at` | 最近一次官方详情核对日期 |

区间车程使用 `min_minutes` 和 `max_minutes`；表格排序按下限，车程上限筛选按区间上限，避免把“2—2.5h”误纳入“≤2h”。

## CSV 与校验

```bash
python scripts/export_csv.py
node tests/test_data.mjs
node --check app.js
```

CSV 使用 UTF-8 with BOM，方便中文 Excel 直接打开；每个路线方案一行。
